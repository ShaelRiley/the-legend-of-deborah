[h1]THE LEGEND OF DEBORAH[/h1]
[b]Public Alpha — a procedural cooperative action-RPG labyrinth for Garry's Mod[/b]

Deborah is trapped somewhere inside an impossible freight-container labyrinth built over gm_flatgrass. Enter as a Hero, descend through a newly generated maze, fight through escalating enemy factions, find the keys, survive the Wardens, rescue Deborah — and then do it again as the labyrinth rebuilds itself.

Every dungeon is procedurally generated. The route, floors, gates, encounters, loot, vertical transitions, enemy composition, and rewards change from run to run while the server validates that the level remains solvable.

[b]The current build is vastly larger than the original Workshop alpha.[/b]

[*][b]Levels 1–20[/b] with experience, class progression, and capstones.

[*]Randomized character generation using 4d6-drop-the-lowest ability rolls.
[*]Large feat system with prerequisites, replacement ranks, class restrictions, active abilities, reactions, movement feats, combat feats, information feats, and magic feats.

[h2]NEW: PROCEDURAL WEAPON APPEARANCE[/h2]
Weapons now visibly reflect their generated properties. Instead of bolting random props onto guns, the current system uses partial weapon finishes, procedural surface treatments, elemental coloration, restrained glow/aura effects, and muzzle presentation while preserving the native Source weapon silhouette.

Fire, Ice, Electric, Earth, Air, and other generated properties can become visually legible before you even open the item sheet.

[h2]NEW: MUCH LARGER ENEMY ROSTER[/h2]
The labyrinth now contains a broad authored enemy roster with distinct movement and combat behavior, including Shamblers, Runners, Soldiers, Deadcrabs, Bio Blasters, Climbers, Nodules, Flamers, Big Crabs, Sentries, Razors, Arc Casters, Lurkers, Beam Sweepers, and other specialized threats.

Enemies use the procedural maze graph for high-level navigation rather than pretending the newly generated container geometry is a normal static map.

[h2]NEW: NEIL, THE BRUTE, AND THE BLACK KEYCARD[/h2]
Late-dungeon progression now includes the Neil hunt and his Brute protector. Neil can flee through the multi-floor maze while the Brute escorts him, reacts to threats, pursues survivors, and commits to a telegraphed charge attack with wall-impact counterplay.

Defeating the hunt advances the Black Keycard sequence and deeper Core progression.

[h2]NEW: GORDON THE WARDEN[/h2]
The final Warden encounter is now a multi-phase boss battle in a dedicated multi-level arena.

Gordon uses a stock citizen presentation with a procedural pig mask — no external model dependency — and brings pursuit, ranged pressure, phase escalation, reinforcements, protected co-op respawns, and a death-only Jail Key progression sequence.

[h2]NEW: 30-MINUTE DUNGEON COLLAPSE[/h2]
Once the Heroes enter a dungeon, the labyrinth is living on borrowed time.

A 30-minute collapse clock governs the active dungeon. Rescue Deborah before time expires. If TIME OVER occurs, the labyrinth enters a cinematic destruction sequence.

Successful rescue resets the next dungeon's clock to 30:00. The timer remains paused during intermission, generation, and staging, then begins when the next Hero deploys.

[h2]STABILITY AND PERFORMANCE[/h2]
A large part of development has focused on making a procedural Source-engine game survive prolonged real play. The current build includes extensive fixes for entity count, wall rendering, hostile scans, minimap networking, reliable-channel pressure, equipment generation, native weapon-grant timing, loot spawning, intermission cleanup, and cross-level state retention.

The project now carries more than one hundred integrated automated regression suites in addition to ongoing native Garry's Mod playtesting.
