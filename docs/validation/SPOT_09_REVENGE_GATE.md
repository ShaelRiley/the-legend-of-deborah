# SPOT-09 predefined finite production gate

The pre-code live GDD 05/07 reconciliation defined the SPOT-09 contracts and
finite gate. This file records the runnable selection before its first aggregate
execution. The executable selector is `tools/test_spot09_gate.py`.

Retain every SPOT-08 selected suite and add `validate_spot09_revenge.lua`, the
actual equipment economy runtime, Magic Hourglass, Damsel progression and staging,
equipment loot and inventory UI regressions. Include canonical manual/rendering
parity, mounted population manifest, accepted Crate assets, whitespace and every
Lua-file syntax check. Each suite has a finite 45-second budget. B29 is invoked
with `--runtime`, not the additional twenty-seed exposure sweep.

The focused harness executes production item dispatch/source binding/staged debit,
procedural choices and conversion, real firearm dice, faction/defenses/native
packet ownership, exact-cell court and jail-slit admission, RunManager completion,
intermission and LootDirector/bag collection. Source entities, time, collision
results and transport are boundary doubles. Client lease/model/pose/slit functions
run against rendering doubles; this is not an image, audio or engine acceptance.
D20's focused handoff uses a boundary observer; the retained Hector suites execute
the actual encounter code. The 512-source conversion sample is deterministic,
not a natural-drop-rate measurement.

The gate snapshots all tracked and nonignored new source before/after, and keeps
per-suite logs and exit codes outside the source tree. A passing selection is not
a full campaign matrix. Native geometry, PVS, animation, gun sounds, tactile
pickup, co-op and performance remain open. Historical failures retain their
original status in `SPOT_09_ATTEMPTS.txt`; later passes never erase them.
